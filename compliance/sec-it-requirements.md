# SEC IT Requirements Review

## Overview

This document summarizes key Information Technology requirements based on SEC Notification No. SorThor 38/2565.

## Key Compliance Areas

### IT Governance

- IT Governance Framework
- Risk Management
- IT Policy Management
- Management Oversight

### IT Security

- Information Security Controls
- Confidentiality
- Integrity
- Availability

### IT Audit

- IT Audit Process
- Compliance Validation
- Security Assessment

## Manager Perspective

As an Infrastructure and Security Manager, these requirements support:

- Security Governance
- Regulatory Compliance
- Risk Management
- Operational Resilience
